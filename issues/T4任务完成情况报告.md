## 一、任务要求回顾

根据集成方案和任务规格，T4任务的核心职责是实现**监控数据读取API**和**智能数据源选择**:

### 核心目标
- **Read API**: 提供GET接口，支持时间范围查询、字段选择和降采样
- **智能数据源路由**: 近实时读Redis，历史读TSDB
- **OpenAPI文档**: 完整的API规范

### API要求
```
GET /monitoring/server/{id}/metrics?from&to&step&fields
GET /monitoring/servers/metrics?fields=cpu,mem,net
```

### 关键功能
1. **时间范围查询**: 支持from/to参数指定查询时间窗口
2. **降采样**: 支持step参数控制数据点密度
3. **字段选择**: 支持fields参数过滤返回字段
4. **数据源选择**: 根据查询时间范围自动选择Redis或TSDB
5. **性能要求**: 近实时 P95 ≤ 300ms, 大盘 P95 ≤ 1.5s

```java
public DataSource selectDataSource(Instant from, Instant to) {
    // 无时间范围 → Redis (最新值)
    if (from == null && to == null) {
        return DataSource.REDIS;
    }

    // 查询在热数据窗口内 (5分钟) → Redis
    if (from != null && from.isAfter(hotDataThreshold)) {
        return DataSource.REDIS;
    }

    // 历史数据 → TSDB
    return DataSource.TSDB;
}
```
