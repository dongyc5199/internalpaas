## 一、任务要求回顾

根据集成方案文档，T2任务的核心职责：

### 输入
- OTLP Export Payload (Protocol Buffer格式)

### 输出
- `List<MetricSample>` 内部统一模型

### 核心功能
1. **单位归一化**:
   - 内存: KB/MB/GB/TB → bytes
   - 时间: ms/μs/ns → seconds
   - 比率: 0-1 → percent (0-100)

2. **标签白名单过滤**:
   - 保留: server.id, region, group, env
   - 过滤: 其他所有标签

3. **指标类型支持**:
   - CPU: system.cpu.usage, system.cpu.utilization, system.cpu.time
   - 内存: system.memory.usage, system.memory.utilization
   - 磁盘: system.disk.*, system.filesystem.*
   - 网络: system.network.io.bytes, system.network.errors
   - 负载: system.load.average.*

### 核心组件
- `OtlpDecoder`: OTLP协议解码器
- `Normalizer`: 数据归一化器
- `MetricSample`: 内部数据模型

### ✅ 2.3 MetricSample 内部模型 (已完成)

**文件位置**: `hub/src/main/java/com/cmict/metricshub/model/MetricSample.java`

**数据结构**:
```java
public class MetricSample {
    private String name;              // 指标名称
    private MetricType type;          // 指标类型: GAUGE/COUNTER/HISTOGRAM
    private double value;             // 指标值
    private String unit;              // 标准单位: bytes/seconds/percent/count
    private Instant timestamp;        // 时间戳
    private Map<String, String> labels; // 过滤后的标签 (仅白名单)

    // Histogram专用字段
    private Long count;               // 样本数量
    private Double sum;               // 值的总和
}
```

**支持的指标类型**:
```java
public enum MetricType {
    GAUGE,      // 即时值 (CPU使用率, 内存使用率)
    COUNTER,    // 累积单调值 (字节发送数, 请求数)
    HISTOGRAM   // 值的分布 (延迟分布)
}
```

**Builder模式**:
```java
MetricSample sample = MetricSample.builder()
    .name("system.cpu.usage")
    .type(MetricType.GAUGE)
    .value(75.0)
    .unit("percent")
    .timestamp(Instant.now())
    .label("server.id", "server-001")
    .label("env", "prod")
    .build();
```

**验证规则**:
- ✅ 必填字段: name, type, unit
- ✅ 自动初始化: labels (HashMap), timestamp (当前时间)
- ✅ 实现: equals(), hashCode(), toString()

## 六、配置化支持

Normalizer支持通过配置文件自定义行为：

```yaml
# application.yaml
metrics-hub:
  normalizer:
    # 标签白名单 (逗号分隔)
    label-whitelist: server.id,region,group,env,custom.tag

    # 是否记录未识别指标 (调试用)
    log-unrecognized: true
```

**配置项**:
- ✅ `label-whitelist`: 可扩展标签白名单
- ✅ `log-unrecognized`: 开关未识别指标日志 (避免日志污染)
