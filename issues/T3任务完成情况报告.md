## 一、任务要求回顾

根据集成方案文档，T3任务的核心职责是实现**双写存储策略**:

### 核心目标
- **Redis**: 热数据存储，最新值查询 (TTL 5分钟)
- **TSDB**: PostgreSQL/Timescale 冷数据存储，历史分析

### 系统架构
```
MetricSample (归一化后)
        ↓
  WritePipeline (协调器)
    ↙        ↘
RedisWriter  TsdbWriter
    ↓            ↓
  Redis      PostgreSQL/Timescale
```

### 关键要求
1. **双写策略**: 同时写入Redis和TSDB
2. **独立错误处理**: Redis失败不影响TSDB
3. **批量写入优化**: 支持批量操作
4. **异步执行**: 支持异步写入（可配置）
5. **监控指标**: 集成Micrometer指标
6. **事务管理**: TSDB写入使用事务

### ✅ 2.6 WritePipeline协调器

**文件位置**: `hub/src/main/java/com/cmict/metricshub/storage/WritePipeline.java`

**核心功能**:
```java
@Component
public class WritePipeline {
    // 双写协调
    public WriteResult writeBatch(List<MetricSample> samples) {
        if (asyncEnabled) {
            return writeBatchAsync(samples);  // 并行异步写入
        } else {
            return writeBatchSync(samples);   // 同步写入
        }
    }

    // 同步双写
    private WriteResult writeBatchSync(List<MetricSample> samples);

    // 异步双写（并行）
    @Async
    private WriteResult writeBatchAsync(List<MetricSample> samples);
}
```

**WriteResult统计**:
```java
public static class WriteResult {
    private final int redisCount;   // Redis写入数量
    private final int tsdbCount;    // TSDB写入数量
    private final int errors;       // 错误数量

    public boolean isSuccess() { return errors == 0; }
}
```

**监控指标集成**:
```java
@PostConstruct
public void init() {
    redisWriteSuccess = Counter.builder("metrics_hub.redis.write.success").register(...);
    redisWriteFailure = Counter.builder("metrics_hub.redis.write.failure").register(...);
    tsdbWriteSuccess = Counter.builder("metrics_hub.tsdb.write.success").register(...);
    tsdbWriteFailure = Counter.builder("metrics_hub.tsdb.write.failure").register(...);
    redisWriteTimer = Timer.builder("metrics_hub.redis.write.duration").register(...);
    tsdbWriteTimer = Timer.builder("metrics_hub.tsdb.write.duration").register(...);
}
```

**错误处理策略**:
- ✅ Redis失败 → 记录警告，继续TSDB写入

- ✅ 双写失败 → 返回错误给调用者，支持重试

**关键特性**:
