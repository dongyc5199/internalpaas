# 升级整体计划

## 第一阶段（第 1 周）：工具链落地
- 安装并锁定 Node.js 版本，初始化 npm 项目。
- 引入 Vite、TypeScript、ESLint、Prettier、Stylelint、Vitest、PostCSS。
- 配置基础目录结构与构建输出，将 Vite 产物指向 `static/dist`。
- 在项目文档中补充新的开发、构建命令。

## 第二阶段（第 2 周）：试点迁移
- 选择 `server-modal` 模块迁移至 TypeScript，构建独立入口。
- 替换对应 Thymeleaf 模板的 `<script>` 引用，验证开发与生产构建。
- 对关键逻辑编写单元测试，总结迁移规范与坑点。

## 第三阶段（第 3 周）：样式与公共能力
- 统一设计令牌、基础样式到 Vite 管线，保证 CSS 变量不变。
- 抽取通用工具模块（HTTP 客户端、事件系统、存储封装）。  
- 梳理第三方库加载方式，减少 CDN 依赖，兼容离线模式。

## 第四阶段（第 4-6 周）：批量迁移与验收
- 按优先级迁移仪表盘、监控、配置编辑器等关键脚本。
- 补充 Vitest 单元测试，必要时探索组件测试或 Playwright。  
- 完成 Maven 与 CI 流程整合，确保 `npm run build` 与 `./mvnw.cmd clean verify` 联合通过。

## 治理与里程碑
- 每周回顾迁移进展、测试情况与风险，更新清单。  
- 保持 CI 全绿，任何失败立即回溯处理。  
- 记录剩余遗留脚本，规划后续迭代（如进一步引入组件库或 SPA 架构）。
