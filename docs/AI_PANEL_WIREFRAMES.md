# AI 面板线框图说明（Wireframes）

本说明配套《docs/AI_PANEL_DESIGN.md》，以线框图（ASCII）+ 交互注释的形式，细化关键视图、状态与流程，指导前端落地实现。

1. 总览与布局约束
- 宽度：侧边栏最小 360px，推荐 400–480px；全宽页面自适应 ≥ 960px。
- 垂直：顶部栏固定、底部输入固定；消息流区域滚动。
- 主题：适配 VS Code 深/浅色；遵循 4.5:1 对比度。
- 字体：与编辑器一致；代码块等宽字体；行高 1.4–1.6。

3. 计划与上下文抽屉（Plan & Context Drawer）

展开“Plan”示意：

+--------------------------------------------------------------+
| [A] 计划抽屉（左侧 40%）                                        |
|  1. [Running] 检查样式结构 (~20s) [⚑低风险] [✎只读]            |
|  2. [Waiting Approval] 生成 Patch [⚑中风险] [✎写文件] → 审核  |
|  3. [Draft] 更新测试                                           |
|  操作：Run Step | Run All | Retry | Skip                      |
|                                                              |
| [B] 上下文抽屉（右侧 60%）                                      |
|  - 打开文件（2）：server.html, drawer.js                      |
|  - 选区摘要（1）：...                                          |
|  - 终端输出（最近 200 行）                                     |
|  - 系统提示（模板）：代码审查 / 安全检查 / 性能优化            |
+--------------------------------------------------------------+

注释
- 步骤含：序号/标题/耗时/风险/权限/关联文件。支持拖拽重排与折叠。
- 等待写操作时进入 Waiting Approval；默认需用户显式确认。
- 上下文项可勾选是否注入；Hover 展示完整路径/字符数/语言类型。

8. 状态与错误变体（States）

- 加载：
  - 顶部栏右侧显示 [Loading ⟳]；发送按钮置为 [Stop ■]。
- 失败：
  - 系统提示：网络不可用/模型不可达/额度用尽；提供“重试/切换模型/离线草稿”。
  - 消息卡片：显示错误摘要与“展开详情”；建议提供错误码与关联请求 ID。
- 禁用：
  - 离线模式：禁用 HTTP 工具与云模型；模型选择器提示“仅本地模型”。

9. 无障碍与焦点顺序（A11y）

焦点顺序（侧边栏）：
1) 顶部栏标题 → 工具按钮组
2) 系统提示（若存在）
3) 消息流（可按 Alt+↑/↓ 在消息间跳转）
4) 抽屉状态条（Plan/Context/Results）
5) 模型选择器 → 参数控件
6) 输入框 → 发送/停止按钮

键盘：
- 打开/聚焦面板：Ctrl+Shift+A / Cmd+Shift+A
- 发送：Ctrl+Enter / Cmd+Enter
- 停止：Esc
- 插入结果：Alt+Enter / Option+Enter
- 在消息间导航：Alt+↑/↓
- 抽屉切换：Ctrl+Alt+1/2/3（Plan/Context/Results）

10. 关键流程（Flows）

流程 A：从输入到应用 Patch
1) 用户在输入框输入 `/fix` + 描述 → Enter。
2) 系统插入“计划”消息，生成步骤 1/2/3 并标记 Running。
3) 步骤 2 需要写文件 → 切换为 Waiting Approval，并弹出 Diff 预览。
4) 用户在 Diff 中 [Apply Hunk] 或 [Apply All] → 写入成功 → 状态变为 Succeeded。
5) 消息流插入“应用结果”卡片，提供 [Undo] 与写入日志链接。

流程 B：模型切换失败
1) 用户打开模型下拉并选择 A 模型 → Loading。
2) 请求失败 → 顶部系统提示显示 Error，模型回退到上一个；提供 [重试] [切换到本地模型]。

流程 C：工具运行与诊断
1) AI 建议运行 `npm test`，用户点击 [Run] → 首次请求权限确认。
2) 运行中显示 stdout/stderr；超时自动停止并支持重试。
3) 失败时提供 [复制日志] [创建 Issue] [回滚] 快捷入口。
