# AI 面板内容显示模块使用指南

> 📅 创建时间：2025-01-21
> 📝 版本：v1.0
> 🎯 目标：为 AI 助手提供丰富的内容展示能力

---

## 📖 概述

AI 面板现已支持丰富的内容显示模块，包括表格、代码块、提示框、步骤指示器、卡片、标签、进度条等多种内容类型。这些模块让 AI 的输出更加美观、结构化且易读。

---

## 🎨 支持的内容类型

### 1️⃣ **基础 Markdown 内容**

#### 表格
标准 Markdown 表格会自动渲染为带斑马纹和悬停效果的美化表格：

```markdown
| 功能 | 状态 | 优先级 |
|------|------|--------|
| 用户认证 | ✅ 完成 | 高 |
| 数据导出 | 🚧 进行中 | 中 |
| 报表生成 | 📋 计划中 | 低 |
```

**带标题的表格**：
第一行不含管道符或管道符很少时，会自动识别为表格标题：

```markdown
猫与狗的性格对比（简明表格）
| 相性 | 猫 (Feliscatus) | 狗 (Canislupusfamiliaris) |
|------|----------------|---------------------------|
| 社交取向 | 独居偏冷，选性社交 | 群居驱动，渴望依附人类 |
| 服从性 | 低，拒令看情 | 高，乐于配合，易驯练 |
```

**效果**：
- 独立的表格标题区域（带蓝色左边框）
- 渐变色表头
- 斑马纹行
- 悬停高亮效果
- 圆角边框和阴影
- 自动识别标题行

---

#### 代码块
支持语法高亮的代码块，会自动显示语言标签：

```markdown
\`\`\`javascript
function greet(name) {
  console.log(`Hello, ${name}!`);
}
\`\`\`
```

**效果**：
- 顶部语言标签条
- Prism.js 语法高亮
- 复制和插入按钮
- GitHub 风格深色主题

---

#### 列表
有序列表、无序列表和任务列表：

```markdown
### 无序列表
- 第一项
- 第二项
- 第三项

### 有序列表
1. 首先做这个
2. 然后做那个
3. 最后完成

### 任务列表
- [x] 已完成的任务
- [ ] 待完成的任务
- [ ] 另一个任务
```

**效果**：
- 彩色标记符号
- 任务列表带复选框
- 悬停效果

---

#### 引用块
使用 `>` 创建引用块：

```markdown
> 这是一段重要的引用内容。
> 它可以跨越多行。
```

**效果**：
- 蓝色左边框
- 渐变背景
- 装饰性引号
- 斜体文字

### 2️⃣ **信息提示框**

使用 `:::type 内容 :::` 语法创建提示框：

#### 信息提示（蓝色）
```
:::info
这是一条重要信息。
:::
```

#### 带标题的信息提示
```
:::info[重要通知]
系统将在今晚 10 点进行维护。
:::
```

#### 警告提示（黄色）
```
:::warning
请注意：此操作不可撤销！
:::
```

#### 成功提示（绿色）
```
:::success
操作已成功完成！
:::
```

#### 错误提示（红色）
```
:::error
发生了一个错误，请重试。
:::
```

#### 小贴士（灰色）
```
:::tip
小提示：你可以使用快捷键 [[Ctrl+S]] 保存。
:::
```

---

### 3️⃣ **结构化内容**

#### 步骤指示器
创建带编号的步骤指南：

```
:::steps
1. 创建数据库连接
   配置连接字符串和凭据

2. 运行迁移脚本
   执行 npm run migrate

3. 启动应用服务
   使用 npm start 命令
:::
```

**效果**：
- 圆形数字标记
- 悬停动画
- 层次分明的标题和描述

---

#### 信息卡片
创建带标题和可选页脚的卡片：

```
:::card[API 端点信息]
**URL**: /api/users
**方法**: GET
**认证**: Bearer Token

返回所有用户列表。

:::footer
最后更新：2025-01-21
:::
```

**效果**：
- 头部标题区域
- 主体内容区域
- 底部页脚（可选）
- 悬停提升效果

---

#### 标签组
显示一组标签：

```
:::tags
前端, React, TypeScript, success:已完成, warning:待审核, error:已过期
:::
```

**效果**：
- 药丸形状标签
- 支持类型着色（success/warning/error）
- 悬停缩放效果

---

#### 进度条
显示任务进度：

```
:::progress[项目完成度] 75%:::
```

**效果**：
- 渐变色进度条
- 动画效果
- 百分比显示

---

### 4️⃣ **特殊内容类型**

#### 徽章
在文本中嵌入小徽章：

```markdown
状态：[badge:success]运行中[/badge]
版本：[badge:primary]v2.1.0[/badge]
警告：[badge:warning]测试环境[/badge]
错误：[badge:danger]已禁用[/badge]
```

**效果**：
- 小型彩色标签
- 大写文字
- 圆角设计

---

#### 键盘快捷键
显示键盘按键：

```markdown
使用 [[Ctrl+C]] 复制，[[Ctrl+V]] 粘贴。
按 [[Enter]] 提交表单。
```

**效果**：
- 3D 按键效果
- 阴影和高光
- 等宽字体

---

#### 分割线
使用 `---` 创建优雅的分割线：

```markdown
---
```

**效果**：
- 渐变淡入淡出
- 细线设计

---

#### 图片
Markdown 图片会自动美化：

```markdown
![描述](https://example.com/image.png)
```

**效果**：
- 圆角边框
- 阴影效果
- 悬停缩放

## 🎯 最佳实践

### ✅ 推荐做法

1. **合理使用提示框类型**
   - `info` - 一般信息
   - `warning` - 需要注意的事项
   - `success` - 成功操作或好消息
   - `error` - 错误或失败
   - `tip` - 小技巧和建议

2. **步骤指示器适合教程**
   - 用于操作指南
   - 配置说明
   - 故障排除步骤

3. **卡片用于独立信息块**
   - API 文档
   - 配置说明
   - 功能介绍

4. **表格展示结构化数据**
   - 对比数据
   - 配置列表
   - 统计信息

5. **进度条显示完成度**
   - 任务进度
   - 项目状态
   - 资源使用率

### ❌ 避免做法

1. 不要过度使用提示框，会造成视觉疲劳
2. 不要在提示框内嵌套提示框
3. 避免在一段回复中使用过多不同的组件
4. 保持内容层次清晰，不要混乱堆砌
