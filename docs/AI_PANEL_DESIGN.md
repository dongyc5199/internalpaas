# AI 面板设计（细化稿）

> 参考 VS Code、TRAE、Qoder 等流行 AI IDE 的界面与交互模式，在现有“AI 面板设计梳理”的基础上细化到可实现层面的规范。

## 0. 设计目标与原则
- 高效完成开发与审查任务：对话、计划、执行、审阅形成闭环。
- 低打扰、强反馈：关键动作明确可见，失败可恢复，成功可复用。
- 可扩展、可组合：工具与模型可插拔，面板与编辑器紧密联动。
- 无障碍与国际化：键盘优先、读屏友好，多语言可切换。
- 一致的 VS Code 语义：主题、快捷键、命令面板、通知样式对齐。

## 1. 用户画像与核心任务
- 初中级开发者：代码修复、生成、解释、重构、单测补全。
- 高级工程师/评审者：变更审阅、风险评估、合规检查、性能建议。
- 运维/脚本作者：脚本生成、日志解读、告警处置与回溯。

核心任务流（示例）：
1) 选中文件/片段 → 触发面板 → 发送意图；
2) AI 生成“执行计划” → 用户逐步 Review/Apply；
3) 产出代码 diff/命令/脚本 → 一键应用/回滚；
4) 记录上下文与决策 → 可重放与复用。

## 2. 顶层信息架构（IA）
- 顶部栏：会话标题、工具按钮（设置/历史/分享/清空）、会话菜单。
- 消息流：对话消息、系统消息、任务进度、文件引用、操作区。
- 底部栏：模型与参数、输入框、发送/停止、快捷提示、Token/耗时。
- 辅助面板（可折叠）：
  - 计划与步骤（Plan）
  - 上下文（文件/选区/变量/系统提示）
  - 工具与运行（工具箱、权限、沙箱/终端）
  - 结果与变更（Diff / Patch / 命令列表）

## 3. 布局与区域规范
- 固定顶部栏；底部输入在面板内固定，消息流区域可滚动。
- 面板宽度自适应，最小 360px；在 VS Code 侧边栏与独立页均保证可用。
- 深浅色主题对齐 VS Code 对应 token 颜色；遵循 4.5:1 对比度。

## 4. 消息模型与展示
- 类型：
  - Assistant（AI）/ User（用户）/ System（系统）/ Tool（工具输出）。
  - 结构化块：代码块（语法高亮）、文件标签、状态徽标、图像缩略、表格。
- 状态徽标：Draft / Running / Review / Applied / Skipped / Failed / Canceled。
- 文件标签：相对路径显示，点击跳转；支持多标签；Hover 显示绝对路径与最近提交信息。
- 代码块：支持语言选择、复制、一键插入当前光标、生成 diff。
- 长消息折叠：超过阈值折叠，提供“展开/折叠”。
- 置顶系统消息：模型切换、参数变更、权限提示固定于最近消息上方。

## 5. 计划与执行模型（Agentic）
- 计划（Plan）：由步骤（Step）组成。属性：序号、标题、预估耗时、风险、所需权限、关联文件。
- 步骤状态机：
  - Draft → Running → Waiting Approval → Succeeded | Failed | Skipped | Canceled。
- 用户控制：
  - 逐步执行（Run Step）/ 全部执行（Run All）/ 失败重试（Retry）/ 跳过（Skip）。
  - Review Gate：默认对写操作（写文件/命令）前插“审核”门。
- 幂等与回滚：对每个写操作生成 Patch/命令预览，Apply 后可 Undo；记录快照以便回滚。

## 6. 输入、命令与快捷键
- 输入框：多行，支持 Markdown；`Enter` 发送，`Shift+Enter` 换行。
- Slash 命令：`/fix` `/test` `/doc` `/refactor` `/explain` `/review` 等，自动补全。
- Prompt 片段：`@文件`、`@选区`、`@终端输出` 快速注入上下文。
- 命令面板集成：提供 `IPaaS: Ask AI`、`IPaaS: Apply Last Patch` 等命令。
- 快捷键（建议，Windows / macOS）：
  - 打开/聚焦面板：`Ctrl+Shift+A` / `Cmd+Shift+A`
  - 发送：`Ctrl+Enter` / `Cmd+Enter`
  - 停止：`Esc`
  - 插入最后结果到编辑器：`Alt+Enter` / `Option+Enter`
  - 在消息间导航：`Alt+↑/↓`

## 7. 模型与参数
- 模型选择：下拉/快速搜索/收藏；最近使用置顶；模型卡片展示上下文长度、价格、擅长领域。
- 常用参数：温度（创意度）、最大 Token、Top‑P、系统提示；提供预设模板（精准/平衡/创意）。
- 切换反馈：系统消息“模型参数已更新”；失败内联错误 + 重试。

## 8. 上下文管理
- 工作区感知：自动附带当前文件路径、语言、选区摘要。
- 内容控制：可显式勾选“包含打开文件/包含变更文件/包含终端输出”。
- 系统提示管理：支持会话级与临时性系统提示；提供常用模板（代码审查、安全检查、性能优化）。
- 隐私阈值：超过 N 行或包含敏感匹配（密钥、证书）时，默认不上传并给出指引。

## 9. 代码变更与文件操作
- Diff 预览：三种视图（并排、内联、拆分）；支持小块逐段应用。
- 应用策略：
  - 一键应用到当前文件/多文件；
  - 批量应用时按文件生成子步骤，逐个 Review；
  - 冲突检测：如果目标文件已变化，提示 Rebase/合并策略。
- 文件写入日志：记录 Patch 清单，支持“复制为 git 补丁”。

## 10. 工具与执行权限
- 工具类型：
  - 文件系统（读/写/搜索）、终端命令、HTTP（可禁用）、数据库查询、本地脚本。
- 权限提示：首次调用需授权；可选择“本次允许/本会话允许/始终允许”。
- 运行视图：实时流（stdout/stderr）、退出码、耗时、可中断；超时自动停止并给出重试。

## 11. 状态与反馈规范
- 通知等级：Success / Info / Warning / Error；顶部 Toast + 内联详情。
- 失败恢复：提供“重试/复制日志/创建 Issue/回滚”快捷入口。
- 空状态：示例提示与快捷命令；首次使用引导卡片。
- Streaming：逐字流输出，提供“暂停流/立即停止/转为卡片”。

## 12. 无障碍与国际化
- 焦点环与可见焦点顺序；跳过到“输入框/最新消息/计划区域”的快捷键。
- ARIA：按钮、菜单、折叠区、进度条、状态徽标均提供语义标签与可读文本。
- 文案多语言：`i18n` 资源文件；中英文对齐；日期/数字/单位本地化。

## 13. 性能与资源
- 懒加载历史消息；仅保留最近 N 条完整内容，其余以摘要折叠。
- 大模型输出分段渲染；代码块虚拟化；图片缩略与延迟加载。
- Token/费用估算：输入/输出 Token 估算与历史总览。

## 14. 安全与隐私
- 局部脱敏：检测并掩码可能的凭据、隐私信息；提供“仍要发送”二次确认。
- 网络策略：遵循离线/受限网络模式；明确第三方调用清单与可关闭开关。
- 数据保留策略：本地缓存加密；可一键清空会话与缓存。

## 15. 可扩展性与集成
- 工具插件 API：定义 `manifest.json`（名称、权限、入口）、`execute()` 协议（参数、stdout/stderr、错误码）。
- 模型适配层：统一推理接口（流式/非流式、函数调用、工具调用）；支持本地与云端模型。
- 与 Git 集成：引用提交、分支对比、生成规范化提交信息、PR 模板。

## 16. 主题与自定义
- 跟随 VS Code 主题 Token；提供局部外观开关（紧凑/舒适、代码字体大小）。
- 消息密度与折叠策略可配置；计划区默认展开项可配置。

## 17. 观测与诊断
- 本地日志：关键事件（模型切换、工具执行、写文件、失败）写入日志；支持导出。
- 诊断面板：最近错误、模型响应耗时、工具成功率。

## 18. 离线与降级
- 离线模式：禁用网络工具与云模型，自动切到本地模型或提示“离线草稿”。
- 降级渲染：不支持图像时，仅展示占位与下载按钮。

## 19. 验收标准（Checklist）
- 键盘可完成从模型切换→输入→发送→审阅→应用的完整闭环。
- 写操作前均有 Review Gate，且支持撤销。
- 失败路径具备明确恢复选项，不出现“死路”。
- 主题、国际化、无障碍达到约束（对比度、ARIA、焦点指示）。
- 大文本与多文件场景下性能可接受（首屏 < 300ms，滚动不卡顿）。

## 20. 示例用例
- 修复：用户选中报错代码 → `/fix` → 生成 Patch → 局部应用。
- 生成：`/test` 生成单测 → 一键创建文件并更新 `pom.gradle`/`mvn` 依赖建议。
- 审查：`/review` 出风险清单 → `Review` 徽标 → 批量应用/忽略。
- 运维：`/script` 生成运维脚本 → 内联运行 → 显示 stdout/stderr → 失败重试。

## 21. 路线图（建议）
- v1：核心对话、计划/步骤、Diff 应用、模型切换、Slash 命令、快捷键。
- v1.1：工具权限与运行视图、失败恢复、日志导出。
- v1.2：插件 API、Git 集成、诊断面板、离线模式。
