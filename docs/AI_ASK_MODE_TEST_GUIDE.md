# AI助手Ask模式测试指南

## 🎯 测试目标

验证AI助手Ask模式的所有功能是否正常工作。

---

## 📋 测试清单

### 环境准备

1. **检查应用状态**
   ```bash
   # Windows
   netstat -ano | findstr ":9090"

   # 应该看到端口9090正在监听
   ```

2. **检查AI配置**
   - 确认 `.env` 文件存在
   - 至少配置了一个AI客户端（Ollama或Moonshot）

   ```bash
   # 查看.env示例
   cat .env.sample
   ```

3. **访问终端管理器**
   ```
   http://localhost:9090/terminal/manager
   ```

## 🐛 常见问题排查

### 问题1: 右下角没有浮动按钮

**可能原因**:
- CSS文件未加载
- JavaScript文件未加载
- 初始化失败

**排查步骤**:
1. 打开浏览器开发者工具（F12）
2. 查看Console标签是否有错误
3. 查看Network标签，确认以下文件是否加载成功：
   - `/css/ai-assistant.css` (200 OK)
   - `/js/ai-assistant.js` (200 OK)
4. 查看Console是否有"AI助手已初始化"日志

**解决方法**:
- 刷新页面（Ctrl+F5 强制刷新）
- 清除浏览器缓存
- 检查文件路径是否正确

---

### 问题2: 点击发送按钮没有反应

**可能原因**:
- 输入框为空
- 正在发送中（按钮禁用）
- JavaScript错误

**排查步骤**:
1. 确认输入框有内容
2. 打开开发者工具查看Console错误
3. 检查Network标签，看是否有请求发出

**解决方法**:
- 确保输入框有文字
- 等待上一条消息发送完成
- 查看Console错误日志

---

### 问题3: AI没有回复或回复很慢

**可能原因**:
- AI服务配置错误
- 网络连接问题
- AI模型响应慢

**排查步骤**:
1. 检查.env配置
2. 查看后端日志
3. 检查Network标签的 `/ai/chat/stream` 请求状态

**解决方法**:
- 验证AI客户端配置（API Key、服务地址）
- 切换到Echo客户端测试
- 检查网络连接

---

### 问题4: 代码块显示异常

**可能原因**:
- Markdown渲染问题
- CSS样式未加载

**排查步骤**:
1. 查看Elements标签，检查代码块的HTML结构
2. 确认CSS文件已加载

**解决方法**:
- 刷新页面
- 清除浏览器缓存

---

### 问题5: 上下文提取失败

**可能原因**:
- terminalManager未初始化
- 终端buffer为空

**排查步骤**:
1. 打开开发者工具Console
2. 输入 `terminalManager`，查看对象是否存在
3. 输入 `aiAssistant.extractTerminalContext()`，查看返回值

**解决方法**:
- 确保先创建至少一个终端连接
- 在终端中执行一些命令后再测试

## 🚀 快速测试脚本

可以使用以下命令快速验证基础功能：

```javascript
// 在浏览器Console中运行

// 1. 检查AI助手是否初始化
console.log('AI助手对象:', aiAssistant);
console.log('终端管理器:', terminalManager);

// 2. 测试上下文提取
if (aiAssistant && terminalManager) {
    const context = aiAssistant.extractTerminalContext();
    console.log('提取的上下文长度:', context.length);
    console.log('上下文预览:', context.substring(0, 100));
}

// 3. 模拟打开面板
if (aiAssistant) {
    aiAssistant.open();
    console.log('面板已打开');
}
```
