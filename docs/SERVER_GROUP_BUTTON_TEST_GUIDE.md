## 📋 快速测试步骤

### 1. 访问应用

打开浏览器，访问：
```
http://localhost:9090
```

### 2. 登录系统

使用默认管理员账号：
- **用户名**: `root`
- **密码**: `admin123`

### 3. 导航到服务器群组管理

登录后，点击侧边栏的 **"服务器群组管理"** 或 **"Server Group Management"**

### 4. 验证表格渲染

**预期结果** ✅:
- 页面显示服务器列表表格
- 表格包含以下列：
  - 服务器名称
  - 状态（在线/警告/离线）
  - 健康分数
  - CPU / 内存 / 磁盘使用率
  - 应用数量
  - 用户数量
  - 运行时间
  - 操作按钮（详情、SSH）

**如果显示"未找到服务器"**:
- 这是正常的，说明数据库中还没有服务器记录
- 可以点击"添加服务器"按钮添加测试服务器

### 5. 测试"详情"按钮

**操作**: 点击任意服务器行的 **"详情"** 按钮

**预期结果** ✅:
1. 右侧弹出详情面板（overlay）
2. 显示"正在加载服务器详情..."加载动画
3. 加载完成后显示服务器详细信息
4. 可以通过以下方式关闭面板：
   - 点击右上角的 "×" 关闭按钮
   - 点击面板外的灰色遮罩区域
   - 按键盘 `ESC` 键

**可能的错误**:
- 如果显示"加载服务器详情失败"，检查服务器ID是否有效
- 检查浏览器控制台（F12）查看具体错误信息

### 6. 测试"SSH"按钮

**操作**: 点击任意服务器行的 **"SSH"** 按钮

**预期结果** ✅:
1. 在新浏览器窗口/标签页中打开SSH终端
2. URL 应该是: `http://localhost:9090/terminal/connect/{服务器ID}`
3. 显示SSH连接界面

### 7. 测试"刷新数据"按钮

**操作**: 点击页面右上角的 **"刷新数据"** 按钮

**预期结果** ✅:
1. 表格数据重新加载
2. 最后更新时间更新为当前时间

## ❌ 常见问题排查

### 问题 1: 表格一直显示"未找到服务器"

**可能原因**:
1. 数据库中确实没有服务器记录
2. API请求失败

**排查步骤**:
1. 打开控制台查看是否有错误信息
2. 检查网络标签，确认 `/admin/server-groups/api/list` 请求状态
3. 如果返回空数组 `[]`，说明数据库中没有服务器，需要先添加

**解决方案**:
- 导航到 **"服务器管理"** 页面添加测试服务器

### 问题 2: 点击"详情"按钮无响应

**可能原因**:
1. JavaScript错误
2. overlay元素未找到

**排查步骤**:
1. 打开控制台查看是否有红色错误信息
2. 检查是否显示"找不到 serverDetailOverlay 元素"
3. 检查页面HTML中是否存在 `<div id="serverDetailOverlay">`

**解决方案**:
- 刷新页面重试
- 如果问题持续，查看 `app_restart.log` 中的错误信息

### 问题 3: 详情面板显示错误

**可能原因**:
1. 服务器ID无效
2. 后端API异常

**排查步骤**:
1. 检查控制台错误：`Failed to fetch server detail`
2. 检查网络标签中 `/admin/servers/{id}` 请求的响应
3. 查看后端日志 `app_restart.log`

### 问题 4: API返回401或403

**可能原因**:
- Session过期
- 权限不足

**解决方案**:
1. 重新登录
2. 确认使用的是管理员账号（root/admin123）
