## 📋 核心要点速览

### 推荐方案的三个核心机制

```
1️⃣ 双向导航同步
   Main App侧栏点击 → React路由更新
   React路由更新 → 侧栏高亮同步

2️⃣ 防循环触发
   isSyncing标志 + lastEventSource追踪
   确保A→B→A不会继续循环

3️⃣ 浏览器历史管理
   React Router负责pushState
   主应用统一验证状态一致性
   back/forward正常工作
```

### 实现的三个关键文件

```
React侧:
  ├─ src/main/frontend/react-app/bridge/navigationBridge.ts
  ├─ src/main/frontend/react-app/bridge/useNavigationBridge.ts
  └─ src/main/frontend/react-app/layout/ShellLayout.tsx

Main App侧:
  └─ src/main/resources/templates/main-layout.html
     (添加NavigationBridge脚本)
```

### 需要验证的三个关键流程

```
✓ 点击侧边栏 → React导航完成 (无循环) → 侧栏更新
✓ React内导航 → 侧栏高亮 (无循环) → 状态一致
✓ Back/Forward按钮 → 应用正确导航 → 历史正确
```
