## 🎯 研究结论

### 最佳实践：多层验证Hook

```typescript
export function useIsEmbeddedMode(): boolean {
    const signals = {
        containerExists: !!document.getElementById('deploy-platform-root'),
        springBootMarker: !!document.querySelector('[data-dev-shell-message]'),
        explicitFlag: container.getAttribute('data-embed-mode') === 'true',
        windowFlag: window.__DEPLOY_PLATFORM_EMBEDDED === true
    };

    return signals.containerExists && 
           (signals.springBootMarker || signals.explicitFlag || signals.windowFlag);
}
```

### 为什么选择这个方案？

| 指标 | 评分 | 说明 |
|------|------|------|
| **可靠性** | ⭐⭐⭐⭐⭐ | 4个独立信号，容错能力强 |
