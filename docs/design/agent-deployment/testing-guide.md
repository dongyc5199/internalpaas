## 🌐 端到端测试

### 环境准备

#### 1. 准备测试服务器

**最低要求**:
- **操作系统**: Linux (Ubuntu 18.04+, CentOS 7+)
- **SSH**: 已启用SSH服务
- **用户权限**: sudo权限（建议配置无密码sudo）
- **磁盘空间**: 至少100MB可用空间
- **端口**: 4317和4318未被占用
- **网络**: 可访问互联网（用于下载Agent二进制）

**配置sudo无密码**:
```bash
# SSH登录到测试服务器
ssh ubuntu@192.168.1.100

# 编辑sudoers文件
sudo visudo

# 添加以下行（将ubuntu替换为实际用户名）
ubuntu ALL=(ALL) NOPASSWD: ALL

# 保存并退出
```

#### 2. 配置主应用

**application.properties**:
```properties
# Agent部署配置
agent.auto-deploy.enabled=true
agent.version=0.91.0
agent.otlp.endpoint=http://localhost:4317
agent.pre-check.min-disk-mb=100
agent.deploy.timeout-minutes=10

# 如果Hub服务在不同机器，修改endpoint
# agent.otlp.endpoint=http://hub-server:4317
```

#### 3. 准备Agent二进制（可选）

**选项A: 使用wget自动下载（推荐）**
- bootstrap.sh 会自动从GitHub下载
- 无需手动准备

**选项B: 手动打包到resources**
```bash
# 下载OpenTelemetry Collector
wget https://github.com/open-telemetry/opentelemetry-collector-releases/releases/download/v0.91.0/otelcol-contrib_0.91.0_linux_amd64.tar.gz

# 移动到resources目录
mv otelcol-contrib_0.91.0_linux_amd64.tar.gz src/main/resources/agent/otelcol-linux-amd64.tar.gz

# 重新编译
mvn clean package -DskipTests
```

## 🐛 故障排查

### 问题1: SSH连接失败

**症状**: 预检查阶段SSH连接测试失败

**可能原因**:
- 服务器地址错误
- 端口错误
- 防火墙阻止
- SSH服务未启动
- 用户名密码错误

**排查步骤**:
```bash
# 1. 手动测试SSH连接
ssh -p 22 ubuntu@192.168.1.100

# 2. 检查防火墙
sudo ufw status

# 3. 检查SSH服务
sudo systemctl status sshd

# 4. 查看SSH日志
sudo tail -f /var/log/auth.log
```

### 问题2: sudo权限不足

**症状**: 安装阶段提示需要密码

**解决方案**:
```bash
# 配置无密码sudo
sudo visudo
# 添加: username ALL=(ALL) NOPASSWD: ALL
```

### 问题3: 文件上传失败

**症状**: 上传阶段报错

**可能原因**:
- SSH会话超时
- 权限不足（/tmp目录）
- 磁盘空间不足

**排查步骤**:
```bash
# 检查/tmp权限
ls -ld /tmp

# 检查磁盘空间
df -h /tmp

# 手动测试SFTP
sftp ubuntu@192.168.1.100
put localfile /tmp/testfile
```

### 问题4: 安装脚本失败

**症状**: 安装执行阶段失败

**排查步骤**:
```bash
# SSH到服务器
ssh ubuntu@192.168.1.100

# 查看bootstrap.sh
cat /tmp/bootstrap.sh

# 手动执行查看详细错误
sudo bash -x /tmp/bootstrap.sh 0.91.0

# 查看systemd日志
sudo journalctl -u otelcol -n 50
```

### 问题5: Agent无法启动

**症状**: 健康检查阶段服务未运行

**排查步骤**:
```bash
# 查看服务状态
sudo systemctl status otelcol

# 查看服务日志
sudo journalctl -u otelcol --no-pager

# 查看Agent日志
sudo tail -f /var/log/metrics-agent/otelcol.log

# 手动启动测试
sudo /opt/metrics-agent/bin/otelcol --config /opt/metrics-agent/config/otelcol.yaml
```

### 问题6: 数据未上报到Hub

**症状**: Agent运行正常但Hub收不到数据

**排查步骤**:
```bash
# 1. 检查OTLP endpoint配置
cat /opt/metrics-agent/config/otelcol.yaml | grep endpoint

# 2. 测试网络连通性
telnet hub-server 4317
nc -zv hub-server 4317

# 3. 查看Agent日志中的错误
sudo grep -i error /var/log/metrics-agent/otelcol.log

# 4. 检查Hub日志
# 在Hub服务器上查看是否收到数据
```

### 部署时间测量

**测试场景**: 测量完整部署流程耗时

```bash

# 创建服务器并记录时间

# ... 执行部署 ...
```
