## 🎨 弹窗模式特性

## 🎨 弹窗模式特性

### ✨ 核心功能

1. **三种导入方式**
   - **自动扫描** - 4步可视化扫描进度,自动检测多客户端
   - **手动指定** - **两步式流程:先选择客户端,再指定路径** ⭐ 新增
   - **文件上传** - 支持拖拽上传配置文件

2. **手动导入两步流程** ⭐ 新特性
   - **步骤1**: 从5个主流SSH客户端中选择(SecureCRT/Xshell/Tabby/MobaXterm/PuTTY)
   - **步骤2**: 指定配置路径(配置目录 or 安装目录)
   - **智能提示**: 根据所选客户端自动显示默认路径
   - **灵活切换**: 支持上一步/下一步,路径类型单选

3. **智能扫描流程**
   - 4步扫描进度可视化
   - 自动检测多客户端并存
   - 扫描结果分组展示
   - 智能去重和合并建议

### 🎨 弹窗模式优势

1. **无缝集成** - 嵌入到服务器群组管理主页面
2. **快速访问** - 一键打开，无需页面跳转
3. **保持上下文** - 背景可见，工作流连贯
4. **灵活取消** - 多种关闭方式（×按钮/取消/点击遮罩）
5. **状态独立** - 关闭后自动重置，不影响主页面

## 🎬 演示流程（最新版本）

1. **启动页面** → 显示步骤1（配置扫描）
2. **顶部横幅** → 展示所有支持的SSH客户端能力
3. **点击"开始自动扫描"** → 4步扫描进度动画
4. **扫描完成** → 显示检测到的多个客户端（如：SecureCRT + Tabby）
5. **智能提示** → 自动统计、去重、合并信息
6. **点击"继续导入"** → 进入步骤2
7. 可随时点击顶部步骤导航返回已完成步骤

## 💡 设计亮点

### 能力展示横幅（新增）⭐
- **徽章式布局**：紧凑、可扩展的客户端列表
- **状态标签**：支持（绿色）、即将（橙色）、计划（灰色）
- **悬浮效果**：鼠标悬停边框变色、阴影、轻微位移
- **视觉层次**：渐变背景突出横幅区域
- **能力传达**：一目了然地展示系统支持的所有SSH客户端

### 智能扫描流程
- **4步扫描过程**可视化动画
- **实时进度条**渐变色设计
- **自动检测多客户端**并存场景
- **扫描结果分组**：每个客户端独立卡片展示
- **智能统计**：自动去重、合并计算

### 交互体验
- 步骤间平滑切换
- 上一步按钮智能显示/隐藏
- 已完成步骤可点击返回
- 所有按钮带悬浮效果
