# 手动导入功能 - 快速使用指南

## 🎯 适用场景

当以下情况发生时,使用**手动指定**导入方式:

- ✅ 自动扫描未检测到SSH客户端
- ✅ SSH客户端安装在非标准路径(便携版/自定义安装)
- ✅ 配置文件存储在非默认位置
- ✅ 系统权限限制导致无法自动扫描
- ✅ 需要指定特定版本的配置文件

---

## 📋 操作步骤

### 步骤1: 选择SSH客户端

1. 在导入弹窗中点击 **"手动指定"** 标签
2. 从5个主流SSH客户端中选择一个:

| 客户端图标 | 名称 | 发行商 |
|-----------|------|--------|
| 🔐 | **SecureCRT** | VanDyke Software |
| 🐚 | **Xshell** | NetSarang |
| 🎯 | **Tabby** | 开源终端 |
| ⚡ | **MobaXterm** | Mobatek |
| 🔧 | **PuTTY** | Simon Tatham |

3. 点击客户端卡片,卡片会显示**紫色边框**和右上角的**勾选图标**
4. 点击 **"下一步 →"** 按钮

### 步骤2: 指定配置路径

#### 选项1:配置目录(推荐)✅

**适用**: 您知道配置文件的确切存储位置

1. 选择 **⦿ 配置目录** 单选按钮
2. 在输入框中填入路径,或点击 **"📁 浏览"** 按钮选择
3. 参考下方的**默认路径提示**

**示例路径**:
```
SecureCRT: C:\Users\YourName\AppData\Roaming\VanDyke\Config\Sessions
Xshell:    C:\Users\YourName\Documents\NetSarang Computer\7\Xshell\Sessions
Tabby:     C:\Users\YourName\AppData\Roaming\tabby\config.yaml
```

#### 选项2:安装目录

**适用**: 您只知道安装路径,让系统自动推断配置位置

1. 选择 **○ 安装目录** 单选按钮
2. 在输入框中填入安装路径,或点击 **"📁 浏览"** 按钮选择

**示例路径**:
```
SecureCRT: C:\Program Files\VanDyke Software\SecureCRT
Xshell:    C:\Program Files\NetSarang\Xshell 7
```

#### 确认导入

3. 填入路径后,**"✓ 确认"** 按钮会自动激活
4. 点击 **"✓ 确认"** 按钮
5. 系统显示确认信息(客户端名称+路径类型+路径)
6. 弹窗底部的 **"确认导入"** 按钮激活
7. 点击 **"确认导入"** 开始导入流程

## 💡 常见问题

### Q1: 如何找到配置文件路径?

**SecureCRT**:
1. 打开SecureCRT
2. 菜单: `Options` → `Global Options`
3. 查看 `Configuration Paths` → `Configuration folder`

**Xshell**:
1. 打开Xshell
2. 菜单: `工具` → `选项`
3. 查看 `高级` → `会话文件夹`

**Tabby**:
1. 打开Tabby
2. 设置 → `配置文件`
3. 点击 `打开配置文件夹`

### Q2: 配置目录和安装目录有什么区别?

| 类型 | 准确性 | 推荐度 | 说明 |
|------|--------|--------|------|
| **配置目录** | 精准 | ⭐⭐⭐⭐⭐ | 直接指向Sessions配置文件,导入成功率100% |
| **安装目录** | 推断 | ⭐⭐⭐ | 系统根据安装路径推断配置位置,可能需要额外查找 |

### Q3: 选错客户端怎么办?

点击步骤2页面左下角的 **"← 上一步"** 按钮,返回客户端选择页面重新选择。

### Q4: 路径输入错误怎么办?

- **未确认**: 直接修改输入框中的路径
- **已确认**: 点击 **"← 上一步"** → 重新输入正确路径

### Q5: 支持同时导入多个客户端吗?

当前版本每次只能导入一个客户端的配置。如需导入多个客户端:
1. 完成第一个客户端的导入
2. 重新打开导入弹窗
3. 选择另一个客户端并指定路径

## 📊 默认路径参考表

### Windows系统

| 客户端 | 配置目录默认路径 | 说明 |
|--------|-----------------|------|
| **SecureCRT** | `%APPDATA%\VanDyke\Config\Sessions` | 会话文件(.ini) |
| **Xshell** | `%USERPROFILE%\Documents\NetSarang Computer\7\Xshell\Sessions` | 会话文件(.xsh) |
| **Tabby** | `%APPDATA%\tabby\config.yaml` | 单一配置文件 |
| **MobaXterm** | `%USERPROFILE%\Documents\MobaXterm\Sessions` | 会话文件 |
| **PuTTY** | `HKEY_CURRENT_USER\Software\SimonTatham\PuTTY\Sessions` | 注册表存储 |

### 环境变量说明

- `%APPDATA%` = `C:\Users\YourName\AppData\Roaming`
- `%USERPROFILE%` = `C:\Users\YourName`
- `%USERNAME%` = 当前登录的用户名

## 🎯 最佳实践

1. **优先使用配置目录** - 导入速度更快,准确率更高
2. **检查路径有效性** - 确保路径存在且包含会话配置文件
3. **备份配置文件** - 导入前建议备份原始配置
4. **测试小范围导入** - 首次使用建议先导入少量会话测试
5. **记录成功路径** - 将成功的导入路径记录下来,便于后续使用
