# 开发者工作台（应用服务调试）页面设计

**版本**: 1.1  
**日期**: 2025-10-27  
**作者**: AI Assistant  
**状态**: 设计提案（待评审）

---

## 1. 设计目标
- 延续现有工作台视觉体系（顶部渐变标题栏、浅灰背景、Poppins/Inter 字体系统）。
- 聚焦“快速定位问题 → 查看运行状态 → 执行调试操作”主流程，减少跳转与层级。
- 保持开发者角色权限边界，仅展示自身可操作的应用服务与工具。
- 交互简洁直接：主要操作区始终可见，辅助信息按需展开，无多余动画或装饰。

## 2. 页面结构总览

```
┌─────────────────────────────────────────────── 顶部栏 (64px) ───────────────────────────────────────────────┐

└────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
┌───────────── 左侧导航 (220px) ──────────────┬───────────────────────────── 主要内容区 (≥ 900px) ─────────────┐
│ • 工作概览                                 │ ┌──────────────────────────── 顶部标签区 ───────────────────┐ │
│ • 应用服务调试 (选中)                      │ │ 服务选择器 | 环境切换 | 状态徽章 | 快捷动作 (重启/发布) │ │
│ • 部署历史                                 │ └─────────────────────────────────────────────────────────┘ │

│ • 个人设置                                 │ │ A 区：运行快照卡片 (CPU/内存/硬盘占用、错误告警)         │ │
│ (底部) 帮助中心 | 反馈                     │ │ B 区：双栏调试面板                                       │ │
│                                             │ │   B1. 日志/事件流 (默认展开)                            │ │
│                                             │ │   B2. SSH 终端 & 快捷命令 (Tab)                        │ │
│                                             │ └────────────────────────────────────────────────────────┘ │
│                                             │ ┌─────────────────── 辅助操作区 ───────────────────────┐ │
│                                             │ │ C 区：配置文件快速入口 | 最近部署 | 审计摘录            │ │
│                                             │ └────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────┴──────────────────────────────────────────────────────────────┘
```

- 左侧导航沿用 220px 固定宽度，当前页（应用服务调试）高亮，底部仅保留必要次级入口。
- 主要内容区采用 12 列栅格（每列 72px + 24px 间距），保证组件对齐与弹性。
- 关键区域 A/B 的高度优先，辅助区 C 自动折行，保持首屏核心信息（状态 + 日志 + 终端）。

## 3. 主流程设计

1. **定位服务**  
   顶部标签区提供服务下拉（支持模糊搜索、最近访问），默认展示当前工作目录关联的服务。选择后加载运行快照、日志和终端会话。

2. **检查状态**  
   A 区显示简明运行指标（CPU 占用、内存占用、硬盘占用、错误&告警汇总）。指标卡采用紫蓝渐变边框呼应开发者主题，数值采用浅色背景，避免视觉噪点，并统一展示趋势提示与阈值。

3. **阅读日志 / 事件流**  
   B1 提供实时日志视图（65% 宽）与事件过滤。默认按 traceId、级别筛选，可切换“实时”与“历史”模式，历史搜索会在右上角显示总条数及导出按钮。

4. **执行调试命令**  
   B2 内嵌受控 SSH 终端，默认进入工作目录根路径。终端上方提供快捷命令栏（如 `tail -f app.log`、`kubectl get pod`），点击即插入。终端与日志互不遮挡，终端可折叠。

5. **回溯与修复**  
   C 区列出最近一次部署信息、与当前服务相关的配置文件入口，以及最近 3 条关键审计记录（含操作人、动作、结果）。点击配置入口会打开滑出面板进行查看/编辑。

## 4. 关键界面元素

### 4.1 顶部标签区
- **服务选择器**：宽 320px，支持清除按钮与键盘导航；显示服务名 + 环境标签 + 版本摘要，下拉为无边框样式，仅保留箭头指示。
- **环境切换**：次要按钮组（如 `DEV`、`STG`、`PROD`），当前环境高亮，切换后整体内容局部刷新。
- **状态徽章**：使用统一状态色（运行中 #22C55E、告警 #F59E0B、异常 #EF4444）。
- **快捷动作**：提供“重启实例”“重新部署”“打开配置”的次要按钮；点击弹出确认对话框，要求填写备注。

### 4.2 运行快照卡片（A 区）
- 四列模块化卡片：CPU 占用、内存占用、硬盘占用、错误 & 告警。
- 每卡包含主数值、阈值提示/趋势文案、更新时间戳；错误卡以橙红强调色突出告警数量。
- 卡片整体高度 148px，圆角 16px，背景使用轻微渐变 `linear-gradient(135deg, #F5F6FF 0%, #FFFFFF 100%)`。

### 4.3 调试双栏（B 区）
- **日志视图**：顶部工具栏包含搜索框、过滤器、时间范围下拉、实时/历史切换。主体采用等宽字体（JetBrains Mono），黑底深灰字或浅色主题可自动适配。支持行号、关键字高亮、暂停滚动。
- **终端面板**：默认为浅色主题，命令输入区固定在底部；显示当前路径、服务器节点、会话时长。违规命令时显示红色警示条并自动截断。
- 日志与终端通过拖拽条可调整宽度（最小宽度 360px），避免强制切换。

### 4.4 辅助区（C 区）
- **配置入口**：列出常用配置文件（application.yml 等），显示上次编辑人/时间及 diff 按钮。
- **最近部署**：展示最新 2 次部署结果（一行含版本号、持续时间、状态标签），附“查看全部”链接跳转部署历史。
- **审计摘录**：列出与当前服务有关的关键操作（终端命令、配置修改等），使用时间线样式。
- **运行洞察弹窗**：页面保留“运行洞察”按钮，弹窗中集中展示配置文件、最近部署、审计摘录三个卡片，避免占用主布局空间。

## 5. 交互与状态

- **加载**：服务切换时展示骨架屏，日志/终端延迟加载并带渐显效果（150ms 内）。
- **终端会话**：开启时提示工作目录路径；10 分钟无操作自动断开，并弹出提示。
- **日志追踪**：点击日志中的 traceId 可在右侧弹出浮层，展示关联请求详情。
- **弹窗放大**：实时日志与 SSH 终端提供弹出按钮，可在独立放大窗口中查看完整内容（高度限制 70vh、最小高度 520px，超出内容内部滚动），支持与主面板同步浏览。
- **运行洞察**：点击顶栏“运行洞察”按钮弹出综合信息面板，可快速浏览配置、部署与审计摘要。
- **错误提示**：所有危险操作（重启、执行脚本）需弹出确认对话框并要求备注；失败时以 toast + 审计记录呈现。
- **快捷键**：提供 `Shift+L` 聚焦日志搜索，`Shift+T` 切换终端，统一在页面帮助提示。
- **响应式**：宽度 < 1280px 时，辅助区 C 自动折叠为底部抽屉；宽度 < 1024px 时日志与终端改为 Tab 切换。

## 6. 视觉规范
- **配色**：沿用开发者主题紫蓝渐变 `#6C63FF → #3D8BFF`；强调色限制在 2 个以内（状态绿/告警橙）。
- **字体**：标题 Poppins 600/18px，正文 Inter 400/14px；日志/终端使用 JetBrains Mono 13px。
- **间距**：模块间距 24px，卡片内边距 20px；按钮与输入框高度 40px，保持可点击性。
- **图标**：统一使用 remixicon 线性风格，线宽 1.5px，尺寸 18px。
- **暗色模式**：背景改为 `#111827`，卡片使用 `rgba(255,255,255,0.04)`，文字对比度≥4.5:1。

---

## 7. 可用性与可访问性
- 页面首屏即可看到服务状态 + 日志 + 终端，减少上下滚动。
- 所有主要操作支持键盘导航与快捷键；终端面板具备屏幕阅读器标签（aria-live polite）。
- 提供“安全提示”信息条，说明终端仅可访问工作目录，避免误操作。
- 日志高亮颜色与背景对比度达到 WCAG AA 要求（≥ 3:1）。

## 8. 实施建议
1. 设计稿：先产出低保真线框验证布局，再依据现有设计系统组件（卡片、面板、按钮）出高保真。
2. 组件复用：日志视图与终端可基于已有组件库扩展，保持一致的样式与交互行为。
3. 性能监测：优先加载关键指标和日志，终端会话按需初始化，避免首屏阻塞。
4. 联调清单：覆盖服务切换、日志检索、终端命令拦截、配置入口、响应式排版等场景。
5. Demo 页面：src/main/resources/templates/developer-workspace-demo.html 已落地初版结构，可用作交互/视觉走查与行为联调（本地访问 file:///E:/work/code/internalpaas/src/main/resources/templates/developer-workspace-demo.html）
