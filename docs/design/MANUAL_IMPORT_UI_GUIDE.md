## 🎨 视觉设计特点

### 颜色主题

| 元素 | 颜色 | 用途 |
|------|------|------|
| **主色调** | 紫色渐变 `#667eea → #764ba2` | 按钮、边框、高亮 |
| **成功色** | 绿色 `#10b981` | 推荐标签、勾选图标 |
| **背景色** | 浅灰 `#fafbfc` / 浅紫 `#f5f7ff` | 卡片背景、输入框 |
| **文字色** | 深灰 `#333` / 中灰 `#666` / 浅灰 `#999` | 标题/正文/提示 |

### 卡片设计

**未选中状态**:
- 边框: 2px solid #e8e8e8 (浅灰)
- 背景: white
- 阴影: 无

**悬停状态**:
- 边框: 2px solid #667eea (紫色)
- 背景: white
- 阴影: 0 4px 12px rgba(102, 126, 234, 0.15)
- 位移: translateY(-2px)

**选中状态**:
- 边框: 2px solid #667eea (紫色)
- 背景: linear-gradient(135deg, #f5f7ff 0%, #faf5ff 100%) (浅紫渐变)
- 阴影: 0 4px 16px rgba(102, 126, 234, 0.25)
- 图标: 右上角显示 ✓ (白底紫字圆形)

### 按钮设计

**主按钮**(下一步/确认):
- 背景: linear-gradient(135deg, #667eea, #764ba2)
- 文字: 白色
- 阴影: 0 2px 8px rgba(102, 126, 234, 0.3)
- 悬停: 上浮1px + 阴影加深

**次要按钮**(上一步/浏览):
- 背景: 白色
- 边框: 1px solid #e0e0e0
- 文字: 灰色
- 悬停: 背景变浅灰

**禁用状态**:
- 背景: #e8e8e8
- 文字: #999
- 鼠标: not-allowed

## 💡 设计原则

1. **渐进式披露** - 每步只显示必要信息,避免认知负担
2. **视觉层次** - 用颜色、大小、阴影建立信息优先级
3. **即时反馈** - 每个操作都有明确的视觉响应
4. **容错设计** - 支持返回、重选、重填
5. **一致性** - 所有交互元素保持统一的视觉语言
