# 服务器详情页设计说明

## 页面定位
- 面向运维与开发负责人，提供单台服务器的运行概览、实时性能态势与关联资源。
- 支持快速判断健康状态与执行常见操作，是服务器管理模块的核心详情界面。

## 布局概述
- 页面采用居中内容区，最大宽度 1240px，背景为浅色渐变以突出主体卡片。
- 内容通过左右布局组合而成：左侧为导航栏，右侧包含服务器概览、实时监控、进程、应用与用户等多个信息分区。
- 各数据区块使用圆角 22px 的白底卡片，配合浅灰描边与柔和阴影，形成层次清晰的卡片式信息架构。

## 导航栏设计
- 左侧 `section-nav` 采用玻璃质感渐变及模糊效果，配合轻量阴影营造现代感。
- 菜单包含“基本信息”“实时监控”“进程信息”“应用情况”“用户信息”，分别锚定 `#server-overview`、`#realtime-monitor`、`#process-info`、`#app-deployments`、`#user-access`。
- 默认状态保持低饱和度；悬停/聚焦时使用线性渐变高亮并伴随轻微位移。`.is-active` 状态通过更强对比度及放大的圆点指示当前区域。
- 前端脚本使用 `IntersectionObserver` 监测滚动并自动切换激活项，点击菜单时同步更新高亮，提供顺滑的跳转体验。
- 移动端（≤1100px）导航转换为横向弹性布局，并调整背景与阴影强度以确保触达效率。

## 核心组件

### 页头
- breadcrumbs 面包屑显示“服务器群组 / 列表 / 服务器详情”，帮助用户确认导航路径。
- 标题区包含服务器名 `prod-core-01`，副标题展示环境、IP 与状态；状态以绿色 `chip` 标示“在线 · 3 分钟前更新”。
- 操作按钮“返回列表”“打开 SSH”分别采用幽灵按钮与次级按钮样式，满足跳转与远程运维需求。

### 服务器概览
- 使用三列 `info-grid` 排布主机名、系统版本、内核、CPU、内存、磁盘、网卡、运行时长、工作目录等关键属性。
- 标签文字 12px 全大写，数值 17px 粗体，兼顾信息密度与可读性。

### 实时资源监控
- 区块操作包含“暂停刷新”“收起图表”；后者通过 `toggleMonitor` 控制监控网格折叠。
- `monitor-grid` 默认双列布局，小屏（小于 900px）下降级为单列。
- 四个 `sub-card` 对应 CPU、内存、磁盘 I/O、网络带宽，分别展示彩色 `tag`、标题、Chart.js 折线图与文字摘要。

### 进程信息
- 行为按钮精简为“刷新数据”“按 CPU 排序”“按内存排序”，避免误触破坏性操作。
- 表格列包含 PID、用户、百分比 CPU、百分比内存、RSS、TTY、状态、已运行时长、命令、操作，满足基础排查需求。
- 示例数据突出高占用进程，并提供每行幽灵按钮示例（终止、查看、降优先级等）。

### 部署的应用
- 表格字段：应用名称（含说明）、版本、负责人、运行状态、端口、最近部署时间、操作。
- 状态 `chip` 区分运行中与待确认，操作按钮示例“滚动重启”“启用”“查看日志”。

### 授权用户列表
- 表格字段：用户名、角色、默认服务、授权类型、最近登录、操作。
- 通过 `chip` 标识角色类型（管理员、运维、开发者），操作按钮示例权限收回、延长或调整角色。

## 交互与动态行为
- 引入 Chart.js CDN 渲染折线图，统一图表动效与配色。
- `UPDATE_INTERVAL = 5000` 毫秒，最多保留 `MAX_POINTS = 36` 个时间点，保证时间轴滚动效果。
- 时间标签使用 `Intl.DateTimeFormat('zh-CN', { hour: '2-digit', minute: '2-digit', second: '2-digit', hour12: false })` 生成，保持本地化格式。
- 折叠后重新展开时利用 `requestAnimationFrame` 触发 `chart.resize()`，确保图表尺寸正确。

## 视觉语言与样式
- 字体栈包含 `"Inter", "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`，兼容多语言环境。
- 主按钮颜色 `#1d4ed8`，搭配浅蓝、青绿、橙色强调不同资源类别；幽灵按钮采用透明背景配浅灰描边。
- 卡片阴影 `0 24px 56px rgba(15, 23, 42, 0.08)` 与圆角塑造柔和层次感。
- `chip` 与 `tag` 背景透明度约 0.16-0.18，语义色（绿色、橙色、蓝色）对应不同状态。
- 表格 hover 使用浅蓝底色提升可读性，边框线条采用低对比度浅灰色。

## 响应式与容器策略
- 关键栅格元素使用 `grid` 与 `flex` 混合布局，提高在不同宽度下的弹性适配能力。
- 图表容器设定 `position: absolute` 填充父级 `chart-wrapper`，并通过固定高度 180px 保持视觉一致。

## 可扩展性建议
- 建议后续将内嵌样式拆分至独立 CSS，并引入设计令牌以便全局复用。
- 交互层可以接入真实监控数据源（WebSocket 或 SSE），替换当前随机模拟逻辑。
- 表格操作按钮应结合权限校验与二次确认弹窗，确保生产环境操作安全。
