1. **事件委托模式**
   ```typescript
   // 全局事件只绑定一次，永久有效
   document.addEventListener("click", (e) => {
       if (e.target.closest('[data-action="modal-close"]')) {
           this.close();
       }
   });
   ```

2. **DOM生命周期管理**
   ```typescript
   // 每次打开前重新查找DOM
   public open() {
       this.modal = document.getElementById("serverImportModal");
       // 避免缓存过期的引用
   }
   ```

## 🎓 经验总结

### 最佳实践

1. **SPA架构下的事件管理**
   - ✅ 使用事件委托模式
   - ✅ 避免缓存会被销毁的DOM引用
   - ✅ 确保事件只绑定一次

2. **单例模式的正确使用**
   - ✅ 用于状态管理
   - ❌ 不用于DOM引用缓存
   - ✅ 分离状态和DOM操作

3. **用户体验设计**
   - ✅ 分步骤降低复杂度
   - ✅ 提供默认值减少输入
   - ✅ 实时反馈增强信心

### 技术挑战

1. **问题**: 页面切换后弹窗失效
   - **根因**: DOM被销毁但引用未更新
   - **解决**: 每次操作前重新查找DOM

2. **问题**: 弹窗无法关闭
   - **根因**: 事件监听器重复绑定
   - **解决**: 采用事件委托模式

3. **问题**: 内存泄漏
   - **根因**: 监听器未清理
   - **解决**: 全局绑定一次，自动管理
