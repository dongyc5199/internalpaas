# 系统设置页面 - 需求改进总结

**版本**: 2.0（改进版）  
**日期**: 2025-10-18  
**改进者**: AI Assistant  
**状态**: ✅ 设计完成

---

## 📋 改进概述

基于用户反馈，将原有的"手动输入路径"方案升级为"智能自动扫描"方案，显著提升用户体验。

---

## 🎯 核心改进点

### 改进1: 引入自动扫描功能

**原方案问题**:
- ❌ 用户需要知道配置文件的具体位置
- ❌ 手动输入路径容易出错
- ❌ 不同操作系统路径不同，学习成本高
- ❌ 对非技术用户不友好

**改进后优势**:
- ✅ 一键自动扫描，零学习成本
- ✅ 多路径智能检测，高成功率
- ✅ 跨平台支持（Windows/macOS/Linux）
- ✅ 失败后提供详细的帮助指引

### 改进2: 支持三种导入方式

```
┌─────────────────────────────────────────┐
│         配置文件获取方式                 │
├─────────────────────────────────────────┤
│                                          │
│  🔍 方式1: 自动扫描（推荐）              │
│     • 系统自动检测配置文件位置           │
│     • 4层检测机制，确保高成功率          │
│     • 适用场景: 软件安装在默认位置       │
│                                          │
│  📁 方式2: 手动指定                      │
│     • 用户指定配置目录或安装目录         │
│     • 系统验证路径有效性                 │
│     • 适用场景: 便携版或自定义安装       │
│                                          │
│  📤 方式3: 文件上传                      │
│     • 直接上传配置文件                   │
│     • 支持拖拽和多文件                   │
│     • 适用场景: 无法访问本地文件系统     │
│                                          │
└─────────────────────────────────────────┘
```

### 改进3: 扩展支持更多SSH客户端

| SSH客户端 | 原计划 | 改进后 | 扫描策略 |
|-----------|--------|--------|---------|
| SecureCRT | P0必须 | P0必须 | 注册表+默认路径+安装推断 |
| Xshell | P1可选 | P1应该 | 注册表+默认路径+版本检测 |
| Tabby | P2未来 | P1应该 | 配置文件直接读取 |
| MobaXterm | P3未来 | P2可以 | 文档目录+安装目录 |
| PuTTY | P3未来 | P3可以 | 注册表枚举 |

## 📊 自动扫描详细设计

### 扫描优先级策略

```
第一优先级: 注册表/系统配置
├─ Windows: 读取注册表项
├─ macOS: 读取plist文件
└─ Linux: 读取环境变量

第二优先级: 默认安装路径
├─ %APPDATA%\VanDyke\Config\Sessions\
├─ ~/Library/Application Support/VanDyke/...
└─ ~/.vandyke/SecureCRT/Config/Sessions/

第三优先级: 从安装目录推断
├─ 检测安装目录
├─ 读取版本信息
└─ 构造配置路径

第四优先级: 历史成功路径
└─ 数据库记录的用户上次成功路径
```

### 扫描结果处理

```java
扫描成功 (SUCCESS):
  ✅ 显示检测到的软件信息
  ✅ 显示会话数量和文件夹数量
  ✅ 提供智能建议（如低峰期导入）
  ✅ 一键继续导入

扫描部分成功 (PARTIAL):
  ⚠️ 找到配置目录但无会话文件
  ⚠️ 提示可能的原因
  ⚠️ 允许用户确认或重新扫描

扫描失败 (FAILED):
  ❌ 列出所有已扫描的路径
  ❌ 说明可能的失败原因
  ❌ 提供3种解决方案:
     • 手动指定配置目录
     • 手动指定安装目录
     • 上传配置文件
```

## 🏗️ 技术架构改进

### 新增组件

```
scanner/ (新增)
├── ConfigScanner.java         # 扫描器接口
├── SecureCRTScanner.java      # SecureCRT扫描器
├── XshellScanner.java         # Xshell扫描器
├── TabbyScanner.java          # Tabby扫描器
└── ScannerFactory.java        # 扫描器工厂

parser/ (新增)
├── ConfigParser.java          # 解析器接口
├── SecureCRTParser.java       # SecureCRT解析器
├── XshellParser.java          # Xshell解析器
└── TabbyParser.java           # Tabby解析器

model/ (新增)
└── ScanResult.java            # 扫描结果DTO
```

### API改进

**新增API**:
```
POST /api/settings/import/scan
  → 自动扫描配置文件

POST /api/settings/import/validate-path
  → 验证手动输入的路径

POST /api/settings/import/infer-config
  → 从安装目录推断配置路径
```

**改进API**:
```
POST /api/settings/import/parse
  增加参数:
  • scanMode: auto | manual | upload
  • installPath: 安装目录（用于推断）
```

**关键亮点**:
- ✨ 零学习成本的一键导入
- ✨ 智能的多路径检测机制
- ✨ 友好的错误提示和帮助
- ✨ 可扩展的架构支持多种SSH客户端
- ✨ 显著提升的用户体验
