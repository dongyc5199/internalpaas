## 📖 使用说明

### 任务清单文档结构

每个任务清单文档应包含以下内容：

1. **任务概览**: 总任务数、预计工期、状态统计
2. **分阶段任务**: 按Phase组织的详细任务列表
3. **任务统计**: 按类型、优先级统计
4. **关键里程碑**: 重要节点和完成标准
5. **执行规范**: 开发/测试/文档要求
6. **检查清单**: 完成标准检查

### 任务状态标记

- ⏳ **待开始**: 任务尚未开始
- 🔄 **进行中**: 任务正在执行
- ✅ **已完成**: 任务已完成并验收
- ⏸️ **暂停**: 任务临时暂停
- ❌ **已取消**: 任务被取消

### 更新规范

1. **每日更新**: 完成任务后在清单中标记 ✅
2. **进度同步**: 更新任务概览中的完成百分比
3. **问题记录**: 遇到问题在对应任务下添加备注
4. **里程碑确认**: 达到里程碑后更新状态
