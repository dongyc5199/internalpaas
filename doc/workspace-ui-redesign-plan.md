# Dev Debug Platform 工作台 UI 设计方案

## 1. 设计目标
- 统一管理员与开发者工作台的布局、配色与交互语言。
- 延续毛玻璃与渐变主题，强化现代化、专业化视觉。
- 精简导航信息架构，突出各角色核心任务。

## 2. 布局框架
- 整体结构：顶部 64px 毛玻璃标题栏 + 左侧 240px 固定导航栏 + 自适应主内容区，背景色 `#F4F5FB`。
- 字体体系：标题使用 Poppins，正文使用 Inter，字号与字重按 18/16/14 px、600/500/400 规范配置。
- 管理员主色渐变：`#2F9BFF -> #3BC6B8`；开发者主色渐变：`#6C63FF -> #3D8BFF`。

## 3. 标题栏设计
- 左侧：平台 Logo + 工作台标识文案（Admin Workspace / Developer Workspace）。
- 中部：自适应搜索框，含放大镜图标与 `Cmd/Ctrl+K` 快捷提示，文案随角色调整（服务器/应用检索）。
- 右侧：通知按钮、主题切换、语言切换、用户中心入口；背景 `rgba(255,255,255,0.75)`，`backdrop-filter: blur(12px)`，底部阴影 `0 8px 24px rgba(15,23,42,0.08)`。

### 3.1 布局与栅格
- 标题栏总高度 64px，左右撑满窗口，背景使用 `rgba(255,255,255,0.75)` 毛玻璃层与 1px `rgba(255,255,255,0.4)` 内描边。
- 左侧/右侧内容区采用 24px 水平内边距，中部搜索区与左右区域之间保持 16px 间距。
- 内容分区采用 12 列弹性栅格，左、中、右区域占比为 3/6/3，确保窗口缩放时搜索区优先收缩。
- 管理员主题使用蓝绿渐变描边（`#2F9BFF -> #3BC6B8`），开发者主题使用紫蓝渐变描边（`#6C63FF -> #3D8BFF`），渐变角度 135°。

### 3.2 元素规范
- **Logo 区域**：容器宽 160px，内含 32x32px Logo 与标题文案；文案字重 600、字号 20px，管理员文案 `Admin Workspace`，开发者文案 `Developer Workspace`。
- **搜索框**：宽度默认 480px，可随窗口缩放，最低宽度 280px。背景 `rgba(15,23,42,0.04)`，圆角 16px，内边距 `0 20px`。placeholder 文案根据角色分别为“搜索服务器 / 快捷键 Cmd/Ctrl+K”和“搜索应用 / Cmd/Ctrl+K”。
- **搜索图标**：左侧嵌入 18px 线性放大镜，颜色 `rgba(15,23,42,0.35)`；快捷键提示为 12px Tags 元素，背景 `rgba(15,23,42,0.08)`，圆角 12px。
- **右侧功能区**：按钮之间保持 12px 间距，排列顺序固定为通知按钮、主题切换、语言切换、用户中心。所有按钮默认尺寸 32x32px，悬浮时透明度从 0.75 提升至 0.9。
- **语言切换**：采用文本按钮，字重 500，字号 14px，默认显示当前语言缩写（如 `ZH`）；Hover 时底部出现 2px 主色渐变下划线。
- **分隔线**：在语言切换与用户中心之间插入 1px 竖向分隔线，高度 24px，颜色 `rgba(15,23,42,0.08)`。

### 3.3 交互与反馈
- 标题栏滚动时保持固定，背景透明度从 0.75 动态提升至 0.92，阴影增强为 `0 12px 32px rgba(15,23,42,0.12)`。
- 搜索框获得焦点时描边变为 1px 主色渐变并出现 0.6s 呼吸光效，键入时展示实时建议列表（下拉最大高度 320px）。
- 搜索框支持键盘快捷键 `Cmd/Ctrl+K` 聚焦；错误态时描边改为 `#F87171` 并在下方显示 12px 错误提示。
- 右侧按钮获得键盘焦点时添加 2px 主色外阴影，按 Enter/Space 触发对应操作；通知按钮在有未读时提供 150ms 轻微晃动动效。
- 标题栏在暗色主题下背景改为 `rgba(15,23,42,0.85)`，内文颜色切换为 `rgba(255,255,255,0.92)`，渐变描边保持不变但亮度提升 8%。

### 3.4 响应式与可访问性
- 窗口宽度 <1280px 时搜索框向右收缩至最小宽度，并在右侧功能区前加入“更多”下拉，将主题切换与语言切换折叠。
- 宽度 <992px 时顶部标题栏高度缩减为 56px，Logo 区域仅保留图标和角色缩写；导航折叠按钮补充到左侧第一位。
- 所有交互控件支持键盘 Tab 顺序：Logo 区域（跳过）→ 搜索框 → 通知 → 主题切换 → 语言 → 用户中心。
- 保证颜色对比度 >= 4.5:1，所有图标提供 `aria-label`，用户中心下拉可通过 Escape 关闭。

## 4. 通知按钮
- 尺寸 32x32px，半透明白背景 + 1px 细描边 + 阴影 `0 2px 6px rgba(15,23,42,0.12)`。
- 18px 铃铛图标使用对应工作台主色渐变，未读状态以红色徽章（白色数字或红点）提示。
- Hover 时背景透明度提升、图标转为实心渐变并伴随轻微浮动；Tooltip 显示“查看通知”。

### 4.1 静态原型说明
- 原型覆盖默认、Hover、未读、焦点、按压五种状态，并区分管理员与开发者配色，确保对齐尺寸与阴影规范。
- 通过数据属性模拟未读徽章与悬浮态，方便日后在组件实现中直接复用。
- 静态页面位于 `doc/prototypes/notification-theme-toggle.html`，可在浏览器打开进行视觉校验。

### 4.2 动效规范
- Hover：0.28s 上浮与描边增强，图标轻抬 1px，突出交互焦点。
- Active：按钮整体缩放 0.96，阴影收紧并保持圆角，图标略微下沉提供按压反馈。
- Focus：追加 3px 主色渐变焦点环并提升阴影强度，满足键盘可访问性。
- Unread：铃铛执行 2.8s 摆动、徽章 2.6s 脉冲提示；Hover/Focus 时暂停避免过度干扰。
- Motion：遵循 `prefers-reduced-motion` 自动关闭摆动与脉冲动效，保留视觉提示。
## 5. 主题切换
- 胶囊按钮（56x32px，圆角 16px），半透明背景与描边，与标题栏风格一致。
- 18px 圆形滑块填充工作台主色渐变，内置当前模式图标（太阳/月亮）。
- 点击滑块平滑移动并切换图标与主题；Hover 展现光晕与 Tooltip，支持键盘焦点与 Space/Enter 触发。

### 5.1 静态原型说明
- 原型展示浅色、Hover、暗色、焦点与按压状态，匹配渐变滑块与背景透明度的设计要求。
- Admin/Dev 两套主题同时呈现，验证不同渐变与焦点环配色。
- 与通知按钮共享原型页面 `doc/prototypes/notification-theme-toggle.html`，文件内附状态说明与辅助文字。

### 5.2 动效规范
- Hover：外框提亮并叠加 0 16px 36px 阴影，滑块出现额外光晕。
- Active：整体缩放 0.97，滑块亮度降低模拟实体开关阻尼感。
- Focus：焦点环触发 1.8s 呼吸光效，强调键盘操作与无鼠标场景。
- Thumb：滑块位移与背景切换保持 0.28s 平滑过渡，Hover 时增强投影。
- Motion：`prefers-reduced-motion` 场景下停用呼吸与光晕动画，保留状态层级。
## 6. 用户中心
- 入口：32x32px 圆角头像按钮，半透明白背景，Hover 时出现光晕。
- 下拉面板：320px 宽、圆角 16px 的毛玻璃卡片（`rgba(15,23,42,0.65)` + `blur(20px)`），顶部显示头像、姓名、账号、角色徽章。
- 快捷操作：个人资料、安全设置、工作台主题等按钮，44px 高圆角矩形，Hover 转为主色渐变。
- 额外链接：管理员可跳转运维/审计，开发者可跳转密钥/CI 状态；底部展示环境与版本标签，以及红色突出“退出登录”按钮。

### 6.1 布局与层级
- 下拉面板固定宽 320px，默认分为用户信息、核心操作、辅助入口、环境/注销四层；管理员版精简为三层（信息、操作、环境/注销），开发者版仅保留单个“问题反馈”快捷入口。
- 顶部信息区采取 1:2 的头像与文本布局，角色徽章改为按需展示（默认隐藏），账号信息使用 12px 字号提示。
- 操作区按钮高度 44px，左右留白 14px，图标容器 28px；管理员仅保留“安全设置”“工作台主题”，开发者仅保留“应用管理”。
- 底部环境 pill 仅用于管理员展示环境标签，开发者面板直接以退出按钮收尾以减少信息噪音。

### 6.2 状态与动效
- 入口按钮覆盖默认/悬停/聚焦/按压状态，光晕与阴影采用角色主色；打开下拉时触发外环 glow。
- 面板支持进入/离场动画：0.25s 垂直平移 12px + 透明度渐变，保证与顶部标题栏衔接自然。
- 操作项在 Hover/Active 时切换为对应主色渐变背景，按压缩放 0.98；仅保留的快捷入口（问题反馈）使用轻量边框高亮。
- 角色徽章如需启用，可附加 2.4s 脉冲动画提示重要事件，同样遵循 `prefers-reduced-motion` 禁用策略。
- 按钮与卡片的阴影、光晕保持与标题栏一致，确保交互感统一。

### 6.3 可访问性与适配
- Avatar 按钮、操作项与快捷链接均支持键盘 `Tab` 聚焦，焦点态添加 3px 渐变描边。
- 面板主体采用 `role="menu"/"menuitem"` 或 `role="switch"` 的语义；快捷键提示使用 11px 字号以保证可读性。
- 深浅主题遵循相同层级与动效逻辑，暗色版文字不低于 4.5:1，可通过变量灵活调整。
- 原型文件：`doc/prototypes/user-center-dropdown.html`，通过 `data-role`、`data-state` 属性模拟不同角色与状态。
## 7. 管理员导航栏
- 顶部用户信息卡片，展示头像、姓名与角色。
- 菜单项：控制台概览、服务器管理、用户权限、审计记录、告警配置、系统配置。
- 选中态：左侧 4px 蓝绿渐变条，背景淡蓝高亮；Hover 采用 `rgba(59,130,246,0.08)`。
- 底部：帮助与反馈按钮、环境标识（DEV/PROD）与版本信息。

### 7.4 图标与资源定义
- 导航图标使用两位大写字母/符号编码（如 OV、SV、AP、WB），在实现阶段映射至 SVG/字体资源以确保可维护性。
- 管理员图标：OV(控制台概览)、SV(服务器管理)、UP(用户权限)、AU(审计记录)、AL(告警配置)、SC(系统配置)、?(帮助/反馈)。
- 开发者图标：WB(工作台概览)、AP(应用管理)、DP(部署任务)、PS(个人设置)、!(问题反馈)。
- 图标主题跟随角色主色（管理员蓝绿、开发者紫蓝），与徽章、指示条保持一致；新图标需在组件库集中登记。
- 相关原型示意：`doc/prototypes/navigation-prototype.html` 顶部新增“导航图标图例”，作为后续开发映射参考。

- 导航展开宽 240px，结构顺序为用户信息卡 → 主菜单 → 底部辅助区；头像卡片使用 40px 圆角矩形，展示姓名与角色描述。
- 管理员菜单按照运维视角排序：控制台概览、服务器管理、用户权限、审计记录、告警配置、系统配置。
- 底部辅助区包含帮助/版本链接与环境 Pill（仅管理员显示环境标签），整体与标题栏毛玻璃风格对齐。

### 7.2 状态与交互
- 选中项左侧显示 4px 渐变指示条并提升背景透明度；Hover 状态使用主色柔和蒙层，Active 态轻微右移 2px。
- 徽章可用于新功能、告警或待处理提示，颜色遵循角色主色渐变；同一菜单内最多两个徽章以避免噪音。
- 收起态宽 72px，仅保留图标与渐变指示条；Hover 时弹出 240px 毛玻璃浮层展示完整文案与徽章。
- 辅助按钮在收起态以图标呈现，并提供 Tooltip 或 Flyout（如帮助）。

### 7.3 角色差异
- 管理员：主色蓝绿渐变，菜单聚焦运维与权限控制，底部展示环境与帮助链接。
- 开发者：主色紫蓝渐变，菜单精简为工作台概览、应用管理、部署任务、个人设置；底部聚合 API 文档、问题反馈、CI 状态。
- 收起态指示条、徽章与 Hover 浮层颜色随角色主题变化，确保区分度。
- 原型文件：`doc/prototypes/navigation-prototype.html`，包含展开/收起态及角色差异状态示意。

## 8. 开发者导航栏
- 顶部团队信息卡片，显示所属项目或小组。
- 菜单项：工作台概览、应用管理、部署任务、个人设置（应用管理内部整合调试、日志、资源模块）。
- 选中态：左侧 4px 紫蓝渐变条，其余交互与管理员保持一致。
- 底部：API 文档、问题反馈、CI 状态等常用链接。

## 9. 导航收起与响应式
- 收起模式宽度 72px，仅展示居中的 24px 图标，选中项保留彩色指示条。
- 悬停时弹出 240px 毛玻璃浮层展示完整菜单与副标题，离开即收回；徽章以小圆点形式贴附图标右上角。
- 辅助按钮也以图标呈现，附 Tooltip，保持可操作性。
- 小于 992px 时导航转换为抽屉式，通过标题栏按钮呼出，动效与样式与桌面版保持一致。
