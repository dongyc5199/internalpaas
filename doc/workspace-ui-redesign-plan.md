# Dev Debug Platform 工作台 UI 设计方案

## 1. 设计目标
- 统一管理员与开发者工作台的布局、配色与交互语言。
- 延续毛玻璃与渐变主题，强化现代化、专业化视觉。
- 精简导航信息架构，突出各角色核心任务。

## 2. 布局框架
- 整体结构：顶部 64px 毛玻璃标题栏 + 左侧 240px 固定导航栏 + 自适应主内容区，背景色 `#F4F5FB`。
- 字体体系：标题使用 Poppins，正文使用 Inter，字号与字重按 18/16/14 px、600/500/400 规范配置。
- 管理员主色渐变：`#2F9BFF -> #3BC6B8`；开发者主色渐变：`#6C63FF -> #3D8BFF`。

## 3. 标题栏设计
- 左侧：平台 Logo + 工作台标识文案（Admin Workspace / Developer Workspace）。
- 中部：自适应搜索框，含放大镜图标与 `Cmd/Ctrl+K` 快捷提示，文案随角色调整（服务器/应用检索）。
- 右侧：通知按钮、主题切换、语言切换、用户中心入口；背景 `rgba(255,255,255,0.75)`，`backdrop-filter: blur(12px)`，底部阴影 `0 8px 24px rgba(15,23,42,0.08)`。

## 4. 通知按钮
- 尺寸 32x32px，半透明白背景 + 1px 细描边 + 阴影 `0 2px 6px rgba(15,23,42,0.12)`。
- 18px 铃铛图标使用对应工作台主色渐变，未读状态以红色徽章（白色数字或红点）提示。
- Hover 时背景透明度提升、图标转为实心渐变并伴随轻微浮动；Tooltip 显示“查看通知”。

## 5. 主题切换
- 胶囊按钮（56x32px，圆角 16px），半透明背景与描边，与标题栏风格一致。
- 18px 圆形滑块填充工作台主色渐变，内置当前模式图标（太阳/月亮）。
- 点击滑块平滑移动并切换图标与主题；Hover 展现光晕与 Tooltip，支持键盘焦点与 Space/Enter 触发。

## 6. 用户中心
- 入口：32x32px 圆角头像按钮，半透明白背景，Hover 时出现光晕。
- 下拉面板：320px 宽、圆角 16px 的毛玻璃卡片（`rgba(15,23,42,0.65)` + `blur(20px)`），顶部显示头像、姓名、账号、角色徽章。
- 快捷操作：个人资料、安全设置、工作台主题等按钮，44px 高圆角矩形，Hover 转为主色渐变。
- 额外链接：管理员可跳转运维/审计，开发者可跳转密钥/CI 状态；底部展示环境与版本标签，以及红色突出“退出登录”按钮。

## 7. 管理员导航栏
- 顶部用户信息卡片，展示头像、姓名与角色。
- 菜单项：控制台概览、服务器管理、用户权限、审计记录、告警配置、系统配置。
- 选中态：左侧 4px 蓝绿渐变条，背景淡蓝高亮；Hover 采用 `rgba(59,130,246,0.08)`。
- 底部：帮助与反馈按钮、环境标识（DEV/PROD）与版本信息。

## 8. 开发者导航栏
- 顶部团队信息卡片，显示所属项目或小组。
- 菜单项：工作台概览、应用管理、部署任务、个人设置（应用管理内部整合调试、日志、资源模块）。
- 选中态：左侧 4px 紫蓝渐变条，其余交互与管理员保持一致。
- 底部：API 文档、问题反馈、CI 状态等常用链接。

## 9. 导航收起与响应式
- 收起模式宽度 72px，仅展示居中的 24px 图标，选中项保留彩色指示条。
- 悬停时弹出 240px 毛玻璃浮层展示完整菜单与副标题，离开即收回；徽章以小圆点形式贴附图标右上角。
- 辅助按钮也以图标呈现，附 Tooltip，保持可操作性。
- 小于 992px 时导航转换为抽屉式，通过标题栏按钮呼出，动效与样式与桌面版保持一致。

## 10. 后续实施计划
1. 拆解标题栏、通知按钮、主题切换、用户中心与导航栏的样式规范，形成组件级 Style Guide。
2. 基于规范制作静态 HTML/CSS 原型，验证布局与收起/展开交互。
3. 整合到 Thymeleaf 模板，按角色渲染对应菜单文案与配色。
4. 执行本地验证与多终端响应式测试，记录问题并迭代。
5. 每项工作完成后，在本文件“进度记录”章节新增完成报告（日期 + 阶段 + 主要产出）。
