现代化导航栏演示

欢迎体验全新的现代化导航栏！这是专为Dev Debug Platform设计的下一代用户界面， 具备流畅的动画效果、响应式主题切换、完美的移动端适配等特性。

快捷操作： 按 Ctrl+B 切换侧边栏，按 Ctrl+Shift+T 切换主题， 在移动端可以通过滑动手势操作导航栏。

JavaScript API

现代导航系统提供了丰富的JavaScript API，方便进行编程式控制：

// 获取导航控制器实例 const nav = window.modernNavController; // 基础操作 nav.toggle(); // 切换侧边栏 nav.expand(); // 展开侧边栏 nav.collapse(); // 收起侧边栏 nav.setTheme('dark'); // 设置主题 nav.getState(); // 获取当前状态 // 事件监听 document.addEventListener('modernNav:sidebarToggle', function(e) { console.log('侧边栏状态:', e.detail.collapsed); });
