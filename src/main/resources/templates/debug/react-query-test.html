Phase 6 手动测试 - T069 (缓存策略) & T070 (乐观更新)

📋 T069: 验证5分钟缓存策略

测试步骤：

  1. 打开浏览器开发者工具 (F12)
  2. 切换到 Network 标签
  3. 点击页面左下角的 React Query DevTools (花朵图标)
  4. 观察初始的 /api/deploy-platform/policies 请求
  5. 刷新页面 (F5) - 预期：没有新的网络请求
  6. 5分钟后再刷新 - 预期：触发新请求（数据变为stale）
💡
提示：在 React Query DevTools 中查看 ['policies', ...] 查询的状态。 Fresh状态表示缓存有效，Stale表示需要刷新。
  • 初始加载显示数据
  • 5分钟内刷新页面无新请求 (缓存命中)
  • 不同筛选条件触发新请求 (查询键隔离)
  • 5分钟后数据标记为 stale

🎯 T070: 验证乐观更新

测试步骤：

  1. 点击任意策略的 切换状态 按钮
  2. 观察：状态徽章立即更新 (无需等待)
  3. 等待1秒后，服务器确认更新
  4. 在DevTools Network中设置 Offline 模式
  5. 再次点击 切换状态
  6. 观察：状态先更新，然后自动回滚并显示错误
⚠️
测试失败场景：在 Network 标签勾选 Offline， 然后点击切换状态按钮，应该看到UI先更新后回滚。
  • 点击按钮时 UI 立即更新 (无延迟)
  • DevTools 显示数据立即变化
  • 成功时：服务器响应后数据保持一致
  • 失败时：显示错误消息
  • 失败时：UI 自动回滚到原始状态
✅ 操作成功！状态已更新。
